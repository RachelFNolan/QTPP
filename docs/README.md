# QTPP documentation

Choose a path based on what you are trying to do:

## Using QTPP

1. Start with the [quick start](../README.md#quick-start).
2. Read the [guided walkthrough](./guided-walkthrough.md) for the in-app
   sample tour, then use the full [user guide](./user-guide.md) as needed.
3. Find short answers in the [FAQ](./FAQ.md).
4. Look up data formats and programmatic workflows in the
   [technical reference](./reference.md).
5. For score formulas and their interpretation, read the
   [scoring guide](./scoring.md). The [benchmark report](../STEP-2-BENCHMARK.md)
   contains measured comparisons and caveats.
