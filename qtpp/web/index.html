Soft scoring weights

These affect ordering preference only; hard template rules are unchanged.

Random valid layouts used to compute “% better than random”. More samples are steadier but slower.

Weight sensitivity

Re-runs the Python baseline for the selected build with each soft-score weight scaled up and down, one at a time, with the same seed. It shows which weights actually change the packets and how big each term is. Results from the stochastic search vary a little, so treat small differences as noise.

Tune weights

Starts from the best build for each selected scorer, then tries many weight combinations with the Python baseline (CP-SAT only responds to the same-packet weight, so it is not searched). Each candidate is rated on a fixed yardstick that does not depend on the weights being tried: every term at weight 1, scaled by what random layouts score, averaged over terms and scorers. The winner is checked on seeds not used to choose it. Afterwards, apply the weights and re-run all builds to confirm.
